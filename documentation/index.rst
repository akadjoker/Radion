Radion documentation
=====================

Radion is a desktop-first 3D game engine written in C++17, built around
OpenGL 4.5 core: a component-based scene graph, a forward renderer, a
real-time editor, a physics and AI toolchain, and its own scripting language
(the Zen VM, bound into the engine as ``ZenBehaviour``/``ScriptComponent``).

These pages describe what the code actually exposes. They are written from
the public headers and the script bindings, so every class and method listed
here exists in the source.
